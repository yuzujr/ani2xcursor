## ani2xcursor v1.6.0

### Changes

- Fix corrupted indexed BMP cursors by honoring the actual color-table length
  (`biClrUsed`). Includes the original contribution from
  [@portasynthinca3](https://github.com/portasynthinca3) in
  [#6](https://github.com/yuzujr/ani2xcursor/pull/6), with additional header and
  palette validation and a fix for small valid cursors. Fixes
  [#5](https://github.com/yuzujr/ani2xcursor/issues/5).
- Add `--size standard` to export 24, 30, 32, 36, 40, 48, and 64px, generating
  missing sizes as needed.
- Add `--resample bilinear|nearest|auto`. Bilinear remains the default; nearest
  preserves pixel-art colors and edges; auto uses nearest neighbor for enlargement
  and bilinear interpolation for reduction. Hotspots are scaled directly once.
- Document KDE/Wayland sizing and manifest precedence, and update shell
  completions and Chinese translations.
- Correct the embedded program version to match the release version. Earlier
  release tags had advanced while `VERSION` still contained 1.4.8.

### Usage

```bash
ani2xcursor /path/to/theme --size standard --resample auto --install
```

If `manifest.toml` exists, its per-role sizes override `--size`. Set
`"24,30,32,36,40,48,64"` for each mapped role in its `[sizes]` section instead.
`--resample` also applies when using a manifest.

### Validation and feedback

The ten ANI files attached to #5 were tested: all 150 native size/frame
combinations matched independently decoded pixels, dimensions, hotspots, and
delays. All three resampling modes passed 300 additional comparisons. The original
corruption was reproduced and the fixed output was visually inspected.

The KDE/Wayland desktop behavior described in
[#7](https://github.com/yuzujr/ani2xcursor/issues/7) has not been verified in a live
desktop session. Please report whether the size preset resolves it on your setup.

These changes were prepared with Codex assistance. My time for this project is
limited, so thank you for your patience. Please continue reporting problems,
ideally with sample files, the command used, and environment details.

### Downloads

- `ani2xcursor-v1.6.0-linux-x86_64.AppImage`
- `ani2xcursor-v1.6.0-linux-aarch64.AppImage`

Download the AppImage for your architecture, make it executable, and run it:

```bash
chmod +x ani2xcursor-v1.6.0-linux-<arch>.AppImage
./ani2xcursor-v1.6.0-linux-<arch>.AppImage --version
```

If FUSE is unavailable:

```bash
APPIMAGE_EXTRACT_AND_RUN=1 ./ani2xcursor-v1.6.0-linux-<arch>.AppImage --version
```

The AppImages are built in a Debian 11 userspace and checked against a glibc 2.31
baseline. On NixOS, use `appimage-run`.
